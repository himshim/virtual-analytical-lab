🎓 Student Practical & Laboratory Manual

A complete step-by-step practical manual for mastering pharmaceutical and chemical instrumental analysis on Virtual Analytical Lab.

1. 🔬 Standard Laboratory Operating Procedure (SOP)

  1. Select Workstation & Analyte: Choose your target instrument (HPLC, UV-Vis, FTIR, or GC-FID) and select a pharmacopoeial sample compound (e.g. Paracetamol, Caffeine, Aspirin, Ibuprofen, Quinine).
  2. Formulate a Hypothesis: Predict physical effects before moving sliders. (e.g., "Increasing % Acetonitrile from 40% to 60% will shorten retention time by decreasing mobile phase polarity").
  3. Execute Acquisition:
    • UV-Vis: Place reference cuvette, click Record Blank, then click Run Wavelength Sweep.
    • FTIR: Collect Background Scan ($I_0$), place sample on ATR crystal, and click Acquire %Transmittance.
    • HPLC: Click Prime Pump, adjust flow rate & mobile phase %B, click Inject Sample & Start Run.
    • GC-FID: Set oven temperature program & carrier gas, click Inject Sample & Start GC Run.
  4. Interpret Features: Check peak symmetry ($T \approx 1.0$), resolution ($R_s \ge 1.5$), plate count ($N$), or functional group bands. Use Tab 3: Learn Hub in each simulator for live calculators.
  5. Log Data: Record retention times and absorbances in the built-in Notebook and export high-res PNG or CSV reports.

3. 🚨 Common Artifacts & Troubleshooting Guide

SymptomProbable CauseCorrective Action
HPLC Peak Tailing ($T > 1.5$)Basic amine interacting with acidic silanolsAdd triethylamine (TEA) modifier or drop pH to 2.5
HPLC Peak Fronting ($T < 0.9$)Column mass overload / strong sample solventDilute sample 10x or dissolve directly in mobile phase
UV-Vis Flat Top ($A > 2.0$)Monochromator stray light / detector saturationDilute sample to enter $0.2 - 1.5\text{ AU}$ linear range
FTIR Spike at $2349\text{ cm}^{-1}$Atmospheric $\text{CO}_2$ purge imbalanceAcquire fresh background scan and purge bench
GC Broad Late PeaksIsothermal temperature too low for high-boilersSwitch from Isothermal to Linear Temperature Program

👨‍🏫 Instructor & Faculty Guide

Comprehensive pedagogical guidance for teaching undergraduate and postgraduate chemistry and pharmacy laboratory courses.

1. 🎯 Educational Objectives & Curriculum Mapping

2. 💡 Recommended Classroom Workflows

• Predict-Observe-Explain (POE) Framework: Have students predict shifts before adjusting %B or oven ramps, observe live signals, and explain using physical equations.
• Blind Unknown Identification: Assign unknown codes from our 14+ compound library. Students verify identity via $\lambda_{\max}$, functional group IR zones, and retention factors ($k'$ / $I$).

3. 🖥️ Teaching Tools & Projection Mode

• 20-Foot Projection Mode: Toggle Projection Mode in the header for high-contrast, enlarged typography and thick graph lines readable from the back of lecture halls.
• Live Learn Hubs (Tab 3): Use interactive Van Deemter / Golay calculators and Purnell resolution sandboxes for engaging live demonstrations.

4. 📝 5 Ready-to-Use Practical Assignments

  1. UV-Vis Assay & pH Shift: Quantitate Paracetamol ($R^2 \ge 0.999$) and observe Phenol Red bathochromic shift ($430 \to 560\text{ nm}$).
  2. HPLC Separation Optimization: Achieve baseline separation ($R_s \ge 1.5$) of Paracetamol + Caffeine by tuning flow rate and % Acetonitrile.
  3. FTIR Carbonyl Ladder: Differentiate Esters, Ketones, and Amides ($1650 - 1750\text{ cm}^{-1}$) and demonstrate ATR $d_p$ wavelength dependence.
  4. GC Carrier Gas Comparison: Compare $N_2$ vs $He$ vs $H_2$ on DB-5 capillary column to prove why Hydrogen enables $2\times$ faster run times.
  5. Kovats Retention Index Calculation: Calculate Kovats Index ($I$) for Limonene and Toluene using homologous $n$-alkane calibration anchors.

🏫 Classroom & Campus Deployment Guide

Technical guide for IT Administrators, Lab Instructors, and Academic Technologists deploying Virtual Analytical Lab.

1. ⚡ Architecture Highlights

• 100% Client-Side Pure Execution: All numerical simulations, FFT transforms, and Canvas renderers execute in the student's browser. Zero backend server load.
• Zero Framework Bloat: Pure vanilla JavaScript ES modules and HTML5 standards.
• Offline & Low-Bandwidth Resilient: Works seamlessly without active internet once loaded.

2. 🚀 Deployment Options

Option 1: Live Cloud Production (Zero Setup)
Direct students to: https://virtual-analytical-lab.vercel.app/

Option 2: Local LAN Classroom Server (Air-Gapped Labs)
Run a 1-line server on the instructor's PC for offline computer labs:

npx serve ./ -p 8080   # Using Node.js
# OR
python -m http.server 8080   # Using Python 3

Option 3: Progressive Web App (PWA) Offline Installation
Click Install Virtual Analytical Lab in Chrome/Edge or Add to Home Screen on Safari iPad for standalone offline operation.
